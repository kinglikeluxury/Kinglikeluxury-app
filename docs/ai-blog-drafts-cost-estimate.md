# تقدير تكلفة مسودات المقالات الذكية

**تاريخ التحقق من الأسعار: 20 أكتوبر 2026.** الأسعار الرسمية المذكورة أدناه موثقة من صفحات المزودين، لكن الإجمالي تقدير مشروط بافتراضات الاستخدام وليس عرض سعر أو موافقة تفعيل.

## الافتراضات الحسابية

- خمس مقالات يومياً (150 شهرياً على أساس 30 يوماً)، واستعلاما بحث أساسيان لكل مقال.
- 10,000 رمز إدخال و5,000 رمز إخراج لكل مقال باستخدام GPT-4.1 mini.
- صورة واحدة لكل مقال باستخدام GPT Image 1، جودة High ومقاس توليد landscape 1536×1024، ثم قصّ/تحجيم إلى 1200×630. يلزم فحص خرج الصورة، ولا يفترض الحساب أن الحجم النهائي أو الجودة مضمونان.
- لا يشمل الترجمة التلقائية، إعادة المحاولة، مراجعات النص، حركة الزيارات/تخزين Cloudinary، الضرائب، أو تغير الأسعار.

## الأسعار والمجموع التقديري

| الجزء | سعر موثق | لكل مقال | خمس مقالات/يوم | 30 يوماً |

| نص GPT-4.1 mini | $0.40/M إدخال و$1.60/M إخراج | $0.012 (الافتراض أعلاه) | $0.06 | $1.80 |
| بحث Tavily Basic | 1 رصيد لكل طلب؛ PAYG $0.008/رصيد | $0.016 لطلبين | $0.08 | $2.40 |

## Cloudinary والحد المقترح

Cloudinary يذكر خطة مجانية بـ25 رصيداً شهرياً، والرصد يستهلك بحسب التخزين والتحويلات وعرض النطاق معاً. لا توجد تكلفة دقيقة لصورة/شهر دون معرفة الخطة والاستخدام الحالي والحركة؛ لذا لم أضف مبلغاً مصطنعاً إلى الإجمالي. السعر المعلن للخطة المجانية لا يضمن أن رصيد الحساب الحالي متاح أو كافٍ.

**حد إنفاق مقترح قبل التفعيل: $55 شهرياً** لتغطية هامش تقريبي فوق $41.70، مع وضع حدود شهرية مستقلة عند المزودين، حد أقصى 150 مسودة و150 صورة، إيقاف تلقائي قبل تجاوز ميزانية البحث/النص/الصورة، إنذار عند 70% و90%، ومنع إعادة المحاولة غير المحدودة. هذا اقتراح فقط؛ لم يُضبط أي حد ولم تُفعّل أي خدمة.

## متطلبات التكامل التي ستلزم لاحقاً

- OpenAI API credential لاستخدام GPT-4.1 mini وGPT Image 1.
- Tavily API key للبحث الأساسي (بديل بحث آخر يتطلب مراجعة مستقلة للسعر والموثوقية).
- Cloudinary cloud name وإعداد رفع آمن للوسائط؛ قد تستخدم الواجهة الحالية unsigned upload، لكن لا ينبغي إعادة استخدامه دون مراجعة قيود المجلد والتحقق من الحجم والنوع.
- سياسة ميزانية وحدود مزودين معتمدة قبل وضع أي مفاتيح تشغيل.
