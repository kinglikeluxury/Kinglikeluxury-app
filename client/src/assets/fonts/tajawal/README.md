# Tajawal Local Font Assets

These WOFF2 files are the Arabic subset of Tajawal, used only by the
Kinglike Family WhatsApp page.

## Source

- Family repository: https://github.com/google/fonts/tree/main/ofl/tajawal
- Source CSS: https://fonts.googleapis.com/css2?family=Tajawal:wght@400;500;700&display=swap
- Files are the official Google Fonts WOFF2 endpoints referenced by that CSS:
  - Regular: https://fonts.gstatic.com/s/tajawal/v12/Iura6YBj_oCad4k1nzSBC45I.woff2
  - Medium: https://fonts.gstatic.com/s/tajawal/v12/Iurf6YBj_oCad4k1l8KiHrRpiYlJ.woff2
  - Bold: https://fonts.gstatic.com/s/tajawal/v12/Iurf6YBj_oCad4k1l4qkHrRpiYlJ.woff2
