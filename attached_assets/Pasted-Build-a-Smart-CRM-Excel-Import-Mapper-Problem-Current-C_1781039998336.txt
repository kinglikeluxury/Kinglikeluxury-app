Build a Smart CRM Excel Import Mapper.

Problem:
Current CRM import fails when Excel column names are different from the app’s expected fields.

Goal:
Allow CRM to import Excel files even if column names vary.

The uploaded Excel may contain columns like:
Lead Owner
Lead Name
Last Name
Phone
Email
Lead Source
Lead Status
Last Activity Time
Origin Country
Budget
Project interesteding purchase
Comment

Map these automatically to CRM fields:

Lead Name / First Name / Name → firstName
Last Name / Surname → lastName
Lead Name + Last Name → fullName
Phone / Mobile / WhatsApp / Contact Number → phone
Email / E-mail → email
Lead Source / Source → source
Lead Status / Status → status
Origin Country / Country → country
Budget / Total Budget → budget
Project interesteding purchase / Project / Interested Project → projectName
Comment / Notes / Description → notes
Lead Owner / Agent / Assigned To → assignedAgent

Required behavior:
1. Accept .xlsx and .csv files.
2. Detect header row automatically.
3. Trim spaces from headers and values.
4. Support Arabic and English headers.
5. Normalize phone numbers:
   - keep + if exists
   - remove spaces and symbols
   - preserve country code
6. Validate email format.
7. If email is missing but phone exists, still import the lead.
8. Skip exact duplicates by phone/email.
9. Show import preview before saving:
   - total rows
   - valid rows
   - duplicates
   - rows with missing phone/email
   - rows with mapping warnings
10. Allow admin to manually adjust column mapping before import.
11. After import, create CRM leads.
12. Imported leads with valid email should start Email Nurturing unless admin checks:
   [ ] Do not start Email Nurturing
13. Imported leads should also create Developer Registration records like normal leads.
14. Do not crash if unknown columns exist.

Important:
Do NOT modify:
- Meta Leads
- WhatsApp AI
- Developer Registration business logic
- Email templates
- Auth
- Payments
- Public property pages
- Blog/SEO

Only improve CRM Excel/CSV import.

Validation:
Test with an Excel file containing these headers:
Lead Owner, Lead Name, Last Name, Phone, Email, Lead Source, Lead Status, Last Activity Time, Origin Country, Budget, Project interesteding purchase, Comment.

Return:
- files changed
- mapping rules added
- test result
- confirmation that import preview works
