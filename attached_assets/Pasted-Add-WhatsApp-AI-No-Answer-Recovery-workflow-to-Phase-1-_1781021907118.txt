Add WhatsApp AI No Answer Recovery workflow to Phase 1.

Important:
Do NOT send real WhatsApp messages yet.
Do NOT connect WhatsApp API yet.
This is draft/preparation only.

Goal:
When a CRM lead status changes to "No Answer 3", create a WhatsApp AI recovery draft message for the same client phone number.

Behavior:
- Detect when lead status becomes exactly "No Answer 3".
- If the lead has a WhatsApp AI conversation, append a new AI draft message.
- If no conversation exists, create one first.
- Mark conversation status as needs_human or draft depending on current logic.
- Add recovery intent to qualification_json:
  recovery_reason: "no_answer_3"
  recovery_triggered_at: current timestamp

AI message rules:
- Arabic by default.
- Polite, calm, respectful.
- No pressure.
- Do not blame the client.
- Do not say "we called you 3 times" aggressively.
- Ask for the best time to contact.
- Ask if they still want investment options.
- Do not prefer any country, city, or project.
- Do not give legal/tax/financial promises.
- Do not send links.
- If client replies later, AI should continue naturally in Phase 2.

Example recovery draft:
"مرحباً أستاذي، حاول فريق Kinglike Luxury التواصل معك بخصوص اهتمامك بالعقارات، ويبدو أن الوقت لم يكن مناسباً. إذا ما زال الموضوع يهمك، أخبرني فقط ما هو الوقت الأنسب ليتواصل معك أحد مستشارينا، أو يمكنك كتابة الدولة/المدينة التي تهمك وسنجهز لك الخيارات المناسبة."

Permissions:
- Admin can see and edit the recovery draft.
- Assigned agent can see it only if the lead is assigned to them.
- Other agents cannot access it.

Logging:
[WhatsAppAI][Recovery] No Answer 3 detected leadId=X
[WhatsAppAI][Recovery] Draft message created leadId=X
[WhatsAppAI][Recovery] No WhatsApp message sent in Phase 1

UI:
Inside WhatsApp AI Conversation card:
- Show recovery draft message clearly.
- Add label: "No Answer 3 Recovery Draft"
- Show trigger time.

Testing:

3. Confirm no WhatsApp message is sent.
4. Confirm admin can see it.
5. Confirm only assigned agent can see it.
