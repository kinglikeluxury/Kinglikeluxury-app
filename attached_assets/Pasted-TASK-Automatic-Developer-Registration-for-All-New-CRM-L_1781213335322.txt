TASK — Automatic Developer Registration for All New CRM Leads

Goal:
Every new CRM lead must be automatically registered with active developer/company registration systems, starting with Silk Development, and later any new developer added to the Developer Registration Center.

Scope:
This applies to leads created from:
- Meta Leads
- Manual CRM entry
- Excel/Zoho import
- WhatsApp leads
- Future lead sources

====================================================
1. Auto Registration Trigger
====================================================

When any new CRM lead is created:

- Automatically create registration queue records for all active developer companies.
- Currently active developer:
  - Silk Development

In the future:
- If admin adds another developer company and marks it Active, new leads should automatically enter its registration queue too.

Do not require admin to manually prepare registration for each lead.

====================================================
2. Re-registration Rule
====================================================

Every successful registration must be automatically scheduled for re-registration after 30 days.

Rule:
- If registration status = Success
- Then set next_registration_date = success_date + 30 days

A background scheduler must check daily for registrations where:

next_registration_date <= today
AND protection status is not stopped
AND lead is still eligible

Then automatically re-register the lead.

====================================================
3. Protection Rules
====================================================

Do NOT auto-register or re-register if:

- Lead is marked Sold
- Lead is stopped
- Lead opted out
- Lead is deleted/archived
- Admin manually stopped registration for that lead/company

Keep existing Stop / Resume buttons.

====================================================
4. Developer Company Rules
====================================================

Developer companies should have:

- is_active = true / false
- auto_register_enabled = true / false
- re_registration_days = 30 by default

If a developer company is inactive:
- Do not register new leads to it.
- Do not re-register existing leads until re-enabled.

====================================================
5. Admin Reports
====================================================

Add admin reporting for Developer Registration Center:

Show:

- Total registrations today
- Successful registrations
- Failed registrations
- Pending / Prepared
- Stopped
- Protected
- Next re-registration due
- Leads registered per developer
- Last registration attempt

Add filters:

- Developer company
- Status
- Date range
- Assigned agent
- Lead source

====================================================
7. Scheduler
====================================================

Create a safe scheduler:

- Runs daily.
- Finds due re-registrations.
- Processes them safely.
- Prevents duplicate runs.
- Logs start/end/result.

Optional admin manual button:
- Run Due Re-registrations Now

====================================================
8. Safety
====================================================

Do NOT modify:

- WhatsApp AI Qualification
- Meta Webhook
- Meta Lead Pull Sync
- Email systems
- Twilio / OTP
- CRM permissions
- Property/project public website

Only modify Developer Registration Center logic.
