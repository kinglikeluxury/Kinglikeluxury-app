Add these two required changes to the AI WhatsApp Qualification Plan v2.0:

1. Post-Completion Incoming Messages Rule

Current plan says that after COMPLETED, further inbound messages are silently ignored by the AI.

Change this behavior:

After qualification is completed:

- AI must stop sending qualification questions.
- AI must not restart the qualification flow automatically.
- AI must not auto-reply to the customer.
- But any future inbound WhatsApp message from the customer must still be:
  1. stored in WhatsApp API Chat History,
  2. linked to the correct CRM lead/conversation,
  3. shown as a new incoming message,
  4. trigger an internal CRM notification for the assigned consultant/admin.

Reason:
We must never lose customer messages after handoff. AI stops, but message logging and CRM notification continue.

2. Duplicate Qualification Prevention Rule

If the same customer phone number appears again from a new Meta Lead form or another campaign:

Before starting a new AI qualification session, check if this phone number already has a completed qualification session within the last 60 days.

If yes:

- Do not start a new AI qualification flow.
- Do not send the greeting/questions again.
- Link the new lead to the existing customer/conversation where possible.
- Add an internal CRM note/notification:
  "Lead already qualified on [date]. Qualification reused."
- Show this status in CRM:
  "Already Qualified"
- Keep all future WhatsApp messages in the same WhatsApp API Chat History thread for that phone number.

If no completed qualification exists within the last 60 days:

- Start the normal AI WhatsApp Qualification flow.

Reason:
Avoid annoying the same customer with repeated qualification questions when they submit multiple Meta forms.
