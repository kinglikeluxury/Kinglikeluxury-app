Update the existing Live Projects feature behavior and admin controls.

Important:

* Do NOT create a duplicate Live Projects page.
* Use the existing Live Projects page/feature that was already created.
* Do NOT change Neon, Railway, database connection, authentication, payments, or deployment settings.
* Before changes, create a checkpoint.

User flow:
When the user clicks the “Live Projects” icon/link from:

* user menu
* admin menu
* web menu
* mobile/app menu

It should open the existing Live Projects page inside the app.

Inside the Live Projects page, show filters in this order:

1. Select Country
2. Select City
3. Select Project

Important behavior:

* Only show projects that have live camera enabled.
* Do not show projects that do not have a live camera.
* After selecting a project, display the live camera video below the filters.
* The live video must appear inside the same page, not in a new tab.
* If the selected project has multiple live cameras, show them as tabs or cards.
* If the iframe/video fails to load, show:
  “Live camera is temporarily unavailable. Please request the latest construction update from our advisor.”
  with consultation/contact CTA.

Admin requirements:
Add live camera controls ONLY for admin users.

When admin creates a new under-construction project, show these fields:

* Enable Live Camera: yes/no
* Live Camera Title
* Live Embed URL
* Live Source Type: iframe / hls / direct / external
* Live Status: active / unavailable / maintenance
* Live Thumbnail
* Live Updated At

When admin edits an existing project, show the same live camera fields.

Visibility rules:

* If admin enables live camera for a project and adds a valid liveEmbedUrl, then this project should appear in the Live Projects page filters.
* If live camera is disabled or URL is missing, the project must not appear in the user Live Projects selection.
* This should apply to both new projects and old projects.

UI requirements:

* Add a LIVE badge for active cameras.
* Use a premium responsive iframe/video card.
* Mobile-friendly layout.
* Keep Kinglike Luxury colors and style.

Testing:

1. Add live camera URL to one existing project as admin.
2. Confirm the project appears under Live Projects.
3. Select country → city → project.
4. Confirm the video appears below the filters.
5. Confirm projects without live camera do not appear.
6. Confirm user and admin menu links open the same existing Live Projects page.
7. Report changed files before publishing.
