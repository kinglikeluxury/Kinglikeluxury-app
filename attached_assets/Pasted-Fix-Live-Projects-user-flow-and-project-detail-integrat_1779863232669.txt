Fix Live Projects user flow and project detail integration.

Current issues:

1. Admin can add a live camera, but it does NOT appear inside the related project detail page.
2. The Live Projects page does not show required filters:

   * Select Country
   * Select City
   * Select Project

Required user behavior:

A) Live Projects page:
When user opens Live Projects page, show 3 required cascading filters:

1. Select Country
2. Select City
3. Select Project

Rules:

* All 3 selections are required.
* Show only countries that have at least one active live camera.
* After selecting country, show only cities that have active live cameras.
* After selecting city, show only projects in that city that have active live cameras.
* Do not show projects without live camera.
* After selecting project, show the live camera video below the filters on the same page.
* If multiple cameras exist for the same project, show camera tabs/cards.

B) Project detail page:
When user opens a project detail page:

* If admin added an active live camera for that project, show the live camera section inside the project page.
* Place it directly under the main project video section.
* Title: “Live Construction Camera”
* Show LIVE badge.
* Render iframe/video inside the page.
* Do not open external links by default.
* If there is no live camera for this project, do not show the live camera section.

C) Admin relation:

* The live camera must be linked to the selected projectId.
* The frontend project detail page must fetch live camera records by projectId.
* The Live Projects page must fetch only active cameras and group/filter them by country/city/project.

D) Validation:

* Make sure the Petra Sea Resort camera already added appears:

  1. in Live Projects page after selecting Georgia → Batumi → Petra Sea Resort
  2. inside Petra Sea Resort project detail page under the project video

E) Do NOT modify:

* Neon connection
* Railway
* auth
* payment
* deployment settings

F) Test:

1. Admin adds live camera to Petra Sea Resort.
2. User opens Live Projects.
3. User selects country, city, project.
4. Camera appears below filters.
5. User opens Petra Sea Resort project page.
6. Camera appears under project video.
